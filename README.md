# 🚲 Bike Sales Dashboard | Microsoft Excel

An interactive **Bike Sales Dashboard** built with Microsoft Excel to analyze customer demographics, purchasing behavior, income, commute distance, and regional trends.

The project transforms raw customer data into an interactive dashboard using **data preparation, Excel formulas, PivotTables, PivotCharts, and visual analytics**.

## 🔎 Key Insights

* Analyzed **1,026 customer records** to identify purchasing patterns.
* Customers with **shorter commute distances** showed higher bike-purchase counts.
* **Income, age, marital status, education, and region** revealed noticeable differences in purchasing behavior.
* Created **age brackets** to make demographic comparisons easier.
* Used PivotTables and visualizations to turn raw customer data into **clear, decision-oriented insights**.
