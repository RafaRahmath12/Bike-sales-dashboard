Bike Sales Performance & Customer Demographics Dashboard
📌 Executive Summary
An interactive Excel data analytics project designed to explore customer demographic factors—such as income level, commute distance, age brackets, and education—to identify the key driver variables influencing bicycle purchases.

📸 Dashboard Preview
🛠️ Data Cleaning & Processing Workflow
Before building the dashboard, the raw dataset underwent key data-cleaning steps in Excel:

Handling Duplicates: Identified and removed duplicate customer record rows.

Data Normalization: Standardized fields such as Marital Status (e.g., converted M / S to Married / Single) and Gender (F / M to Female / Male).

Feature Engineering: Built a custom Age Bracket column using nested IF formulas to categorize customers into age groups (Adolescent, Middle Age, Old).

Data Formatting: Configured income values into currency formats and adjusted numerical continuous ranges for clean aggregation.

💡 Key Business Insights
Income Impact: Higher-income customers show a significantly higher rate of purchasing bikes compared to lower-income segments across all regions.

Commute Distance: Customers with short commutes (0–1 miles) show the highest purchase conversion. Conversion declines as commute distance increases beyond 5 miles.

Age Demographic: The Middle Age group accounts for the majority of bike buyers, making them the primary target audience for marketing campaigns.

🛠️ Tech Stack & Skills Demonstrated
Tools: Microsoft Excel (PivotTables, PivotCharts, Slicers, Data Formatting).

Techniques: Data Cleaning, Categorical Grouping, Feature Engineering, Dynamic Filter Setup.
